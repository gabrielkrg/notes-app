# Notes

## Platform

web

React interface shared in separate browser/mobile and Tauri desktop source trees.

## Product Purpose

Read and organize notes that remain ordinary files on disk. The desktop app also creates, edits, renames, and deletes files. See README.md for the established product behavior.

## Capabilities and Constraints

Preserve folder navigation, search, bookmarks, graph, annotations, reading preferences, split panes, and keyboard shortcuts. Folder attachment and writing require desktop capabilities. GitHub repositories provide additional read-only notes. Preferences persist on the device. Keep browser and desktop interfaces aligned.

## Users

Inferred from the existing app: people reading and maintaining a personal file-based notes library. No narrower audience was specified.

## Current Request

Remake the existing interface with modern layout, color, typography, spacing, and settings selection, using Impeccable. No product or storage changes were requested.
